# Telegram Agent Hub（中文说明）

在 Telegram 里统一管理你所有的 AI 编程 agent：多个 Claude Code 订阅账号、Codex，跨 Windows / Mac 多台电脑。手机上就能和每个项目会话聊天、点按钮批准有风险的操作、开新项目或接上旧项目、看额度，还能让 agent 之间互相派活。

安装步骤、配置项、命令表见 [README.md](README.md)。下面是整套规则。

## 群和角色

| 群 | 谁在里面 | 作用 |
|---|---|---|
| 上朝（指挥群，普通群） | 你 + 每台电脑的 bot | 布置任务、看回报；也是两台电脑之间的通道（心跳、跨机派活、搬家包、更新包） |
| Claude_A_Win | Windows 的 bot | Claude 账号 A（称呼 `@a`） |
| Claude_B_Win | Windows 的 bot | Claude 账号 B（`@b`） |
| Codex_Win | Windows 的 bot | Codex（`@codex`） |
| Claude_Mac | Mac 的 bot | Mac 上的 Claude（`@mac`） |

每个 agent 群（开启「话题」的超级群）：
- 「圣旨」（General 话题）= 本群调度员；其它每个话题 = 一个项目会话。
- 群置顶 = 用量面板；话题置顶 = 会话卡片。
- 调度员（上朝、圣旨）只分派、不干活：没有读写文件和运行命令的工具。圣旨能找目录、开话题、交接；具体工作一律在项目话题里做。调度员的规则一改，就自动开新对话。
- 新任务（调研、杂事也算）一律在 workspace 下按任务建子文件夹（例如 `search`），话题名就是文件夹名；不能直接用 workspace 根目录开话题。

## 在上朝里布置任务

- 分工：**上朝只决定交给哪个号；具体开哪个项目、建话题，由那个号自己群里的「圣旨」处理。**
- 开头写称呼就是点名，比如 `@a 修一下登录 bug`（普通文字，不是 Telegram 的 @）。点名的消息由 Hub 直接贴到那个群的「圣旨」，不经过上朝的 AI，也不确认。
- 不点名：总调度（config `commandDefault` 那台电脑）判断交给谁，弹按钮让你确认后转过去。没点按钮、直接发新消息 = 按新消息处理。
- 消息里出现 config `commandRoute` 的关键词（比如 Mac / 麦克 / 苹果）就归那台电脑处理；两台 bot 用同一套规则，不会重复接单。
- 回报到上朝：先是「📋 圣旨：交给了哪个话题」（或直接回答），话题那一轮做完再回「✅ 做完 / 💬 在等你回复 / ⚠️ 没做完」。

## agent 之间

- 同一项目话题里自己做；属于另一个已有项目，就 `handoff` 给那个话题。
- 找别的号或另一台电脑：`send_to_agent(@称呼, 任务)`，任务进对方群的「圣旨」。跨机时在上朝发「📨 → Mac …」，两台 bot 在上朝里能直接看到彼此的消息。每一步都在上朝留痕。
- 结果回传：对方做完后，结果除了回报上朝，还会以「📬 你派出去的任务有结果了」送回发起的话题，由它接着做。
- 对方不在线（心跳超过 12 分钟没更新）：不发，直接告诉你「🏖 Mac 今天请假了（最后在线 hh:mm）」，也不存着等它上线补做。每台电脑只处理 10 分钟内收到的消息；更新包例外，上线后照样装最新的。
- 防循环：交接链最多 3 跳；每个话题每小时最多主动派 10 次（`handoffPerHour`，0 = 不限）；你在那个话题亲自发消息后，两个计数都清零。

## 模型和额度

- 调度员：Sonnet + 低思考强度，只做分派。项目话题：账号默认模型，`/model` 按话题或按群改。
- 用量 ≥ 90%：私聊提醒，一键把该账号的会话切到另一个账号（`/account` 手动切，记忆不变）。
- 做到一半额度用完：弹出「切到另一个号马上继续 / 等重置后自动继续 / 先不管」，不选就到重置时间自动接着做。

## 权限

- 默认 auto：常规操作自动放行，有风险才弹卡片；`/mode ask|auto` 按话题或按群改，不提供全部免审。
- 卡片按钮：允许一次 / 🔁 本会话都允许 / 拒绝。内容太长会标明「截断」，看不全就别批。
- 桌面 App / 终端会话的权限请求也能推到手机：在那台电脑的群里发 `/approvals on`。
- 整台电脑都可以 `/open`，只有 Hub 自己的目录不行。bot token 不进 agent 的环境变量；任何提到 Hub 密钥的操作都会被拦（防误读，不是沙箱）。
- 上朝里只认 config `peerBots` 写明的对方 bot，其它 bot 一律不理。更新包、搬家包默认要你点确认（`confirmBundles: false` 才自动接收），包里有符号链接的整个拒收。

## 记忆

- 同一台电脑上换账号：对话记录共用 `~/.claude`，`/account`、`/fork` 都带完整记忆。
- 跨电脑：`/move mac`（只带记忆）或 `/move mac code`（连代码，不含 node_modules / .git / 构建产物 / .env，不覆盖已有文件），对方在线才能搬，包最大 20 MB。搬走后，原话题再发消息会先问你「继续会分叉」。
- 同一个会话不会被两个话题同时驱动：已经在用时，`/open` 自动复制一份带完整记忆的副本。

## 运维

- 开机自启、崩溃自动重启；轮询卡住 3 分钟就自己退出、等系统重启（刚从睡眠醒来不算）。Mac 运行 Hub 时防止空闲睡眠。
- 心跳写在群简介里（带版本号）；对方掉线超过 30 分钟会私聊提醒你。
- 每天 04:00 更新 Agent SDK，只装发布满 3 天的版本，先自检，失败就回滚。另一台电脑用 `node scripts/push-update.mjs` 远程更新：先检查再装，旧版本留在 `prev/`，新版本连续崩溃 3 次就自动退回。
- 部署新版本不打断任务：在 `hub.mjs` 旁边建一个 `restart.flag`，等所有话题空闲了 Hub 才自己重启。万一被崩溃、断电打断，重启后自动接着做那一轮（只自动续一次）。
- 删除话题不会丢记忆；`/clear` 清空群里的话题和消息（用量面板保留）。

## 命令

`/open` `/new` `/sync` `/fork` `/handoff` `/move` `/account` `/model` `/mode` `/stop` `/get` `/status` `/approvals` `/clear` `/start`（帮助）
